Qura Sakhi (renamed from "Saathi" on Oct-18; internal JS API is still `window.Saathi`, localStorage key `qura-saathi-v1`) = free bilingual (EN+HI) reproductive-health utility app for Indian women, social-service arm + lead funnel for Qura. Working UI prototype only (localStorage, nothing sent); compliance (CDSCO, DPDP, DMR) to be secured before launch. Follows [[project-cycle-tracking-flo-assessment-oct18]].

- Artifact: https://claude.ai/artifact/25aocCU68U1DHebpjTmne6 — v5 (Oct-18 ~18:00 IST, renamed Sakhi): core + 17 modules (108 screens, 98 Care tiles) + Learn library (69 articles, 8 groups, fact-checked + humanized).
- Source of truth: `docs/_saathi-prototype-oct18/` (untracked). Core = app.js/app.css; each care area = `mods/<id>.js` registering via `Saathi.register` (contract in MODULE_API.md, agreed routes in mods/routes.json). `python3 build.py` wires module script tags; `node test/check.mjs <id> --shots` (per-module, EN+HI, clicks) and `node test/smoke.mjs .` (all routes) need Playwright from the main repo's node_modules.
- **Modules are UNREVIEWED** except pregtest + pregtools. Mohit stopped the review workflow and said "proper QA review later". Next step = per-module review (facts vs official sources, safety rules, BAMS scope, Hindi, humanizer) + cross-module consistency check, then republish.
- Gated (needs legal/clinical sign-off before launch): abortion info, kick counter, contraction timer, symptom checkers, preg logs thresholds, PBAC, lab flags, post-birth recovery/mood, insights feed, TTC counter.

**Why:** Indian women don't pay for apps like Flo; Saathi is free and feeds Qura leads via "Book a free call".
**How to apply:** Build on ~/Desktop/QuraSakhi (docs/_saathi-prototype-oct18 is a mirror), not the scratchpad. Don't switch model/effort or interrupt while a build workflow runs — it killed all running agents on Oct-18.
